โปรแกรมนำเข้าข้อมูลศูนย์บริการ -> Express  (คู่มือใช้บน Windows)
==================================================================

** Windows 7 **
  - ใช้ไฟล์ ExpressImport.exe จาก GitHub Actions ได้เลย (build เป็น 32-bit/Python 3.8 รันได้ทั้ง Win7/10/11)
  - เปิดหน้าจอด้วย Chrome / Firefox / Edge  (อย่าใช้ Internet Explorer - หน้าจอจะเพี้ยน)
  - ถ้าจะรันด้วย Python บน Win7 ต้องลง Python 3.8 (เวอร์ชันใหม่กว่านี้ลง Win7 ไม่ได้)


ไฟล์ที่ต้องคัดลอกไปเครื่อง Windows (วางไว้โฟลเดอร์เดียวกัน):
  - express_gui.py            (หน้าจอโปรแกรม)
  - express_import.py         (เครื่องยนต์เขียน DBF)
  - Run-Express-Import.bat    (ปุ่มเปิดโปรแกรม)
  - build_windows.bat         (ไว้สร้าง .exe เท่านั้น ถ้าต้องการ)

------------------------------------------------------------------
วิธีที่ 1  (ง่ายสุด - ใช้ Python บนเครื่อง)
------------------------------------------------------------------
1) ติดตั้ง Python ครั้งเดียว: https://www.python.org/downloads/
   ** ตอนติดตั้งให้ติ๊ก  "Add Python to PATH" **
2) ดับเบิลคลิก  Run-Express-Import.bat
   (ครั้งแรกจะติดตั้ง xlrd ให้อัตโนมัติ)
3) เบราว์เซอร์จะเปิดหน้าจอโปรแกรมขึ้นมา
   - กดเลือก "โฟลเดอร์ฐานข้อมูล" ชี้ไปที่ฐานข้อมูล Express  เช่น  Z:\NS68-69
   - กดเลือก "ไฟล์ Excel" ที่จะนำเข้า
   - กด ดูตัวอย่าง / ตรวจสอบ / บันทึก

------------------------------------------------------------------
วิธีที่ 2  (ทำเป็น .exe ไม่ต้องลง Python บนเครื่องที่ใช้งานจริง)
------------------------------------------------------------------
* ต้อง build บนเครื่อง Windows ที่มี Python (สร้างจาก Mac ไม่ได้)
1) บนเครื่อง Windows ที่มี Python ให้ดับเบิลคลิก  build_windows.bat
2) ได้ไฟล์  dist\ExpressImport.exe
3) ก๊อป ExpressImport.exe ไปเครื่องไหนก็ดับเบิลคลิกใช้ได้เลย (ไม่ต้องลง Python)

------------------------------------------------------------------
ข้อควรระวังก่อน/หลัง "บันทึกลงระบบจริง"
------------------------------------------------------------------
- ปิดโปรแกรม Express ก่อนกดบันทึก (กันไฟล์ถูกล็อก)
- โปรแกรมจะสำรองไฟล์ DBF/CDX ให้อัตโนมัติ (โฟลเดอร์ _backup_...)
- หลังบันทึก เปิด Express -> เริ่มระบบ -> จัดการแฟ้มข้อมูล ->
    (1) จัดเรียงดัชนีใหม่ (Reindex)
    (2) คำนวณยอดบัญชี/ยอดยกมาใหม่
