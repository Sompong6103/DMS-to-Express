# DMS-to-Express

โปรแกรมนำเข้าข้อมูลงานบริการ (ศูนย์บริการ) จากไฟล์ Excel ที่ส่งออกจากระบบ DMS
เข้าสู่ฐานข้อมูล **โปรแกรมบัญชี Express** (FoxPro/DBF) โดยตรง
สร้างเป็นบิล **ขายเงินสด-ศูนย์บริการ** (`HC{ปีเดือน}/{เลขรัน}`) — รวมงานตามวันที่เป็น 1 บิล

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `express_import.py` | เครื่องยนต์อ่าน xls → เขียน DBF (CLI: `preview` / `verify` / `commit`) |
| `express_gui.py` | หน้าจอใช้งาน (เว็บในเครื่อง) เลือกโฟลเดอร์ DB + ไฟล์ xls แล้วกดทำงาน |
| `Run-Express-Import.bat` | เปิดโปรแกรมบน Windows (ต้องมี Python) |
| `build_windows.bat` | สร้าง `ExpressImport.exe` บน Windows |
| `เปิดโปรแกรมนำเข้า-Express.command` | เปิดโปรแกรมบน macOS |

## สร้างไฟล์ .exe ด้วย GitHub Actions
push ขึ้น branch `main` หรือกด **Run workflow** ในแท็บ **Actions** →
ดาวน์โหลด `ExpressImport.exe` ได้จาก **Artifacts**
(ติด tag เช่น `v1.0` จะแนบไฟล์เข้า **Releases** ให้ด้วย)

## ความปลอดภัย
ไฟล์ฐานข้อมูลจริง (`*.DBF`, `*.CDX`, `*.xls`, โฟลเดอร์ `NS68-69*`, backup, config)
ถูกกันไว้ใน `.gitignore` แล้ว — **ไม่ถูกอัปโหลดขึ้น repo** และควรตั้ง repo เป็น **Private**

## ขั้นตอนก่อน/หลังบันทึกลงระบบจริง
1. ปิดโปรแกรม Express ก่อนกดบันทึก (กันไฟล์ล็อก) — โปรแกรมสำรองไฟล์ให้อัตโนมัติ
2. หลังบันทึก: Express → เริ่มระบบ → จัดการแฟ้มข้อมูล → จัดเรียงดัชนีใหม่ + คำนวณยอดบัญชีใหม่
